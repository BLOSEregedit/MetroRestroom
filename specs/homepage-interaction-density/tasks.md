  - 智能定位站左侧显示定位针；其他站点圆点点击后锁定为手动计算起点。
  - 圆点点击与顶部“更换”复用同一手动起点状态和持久化逻辑。

  - 按 `targetIndex < originIndex` 验证同线调头状态，只在当前高亮卡显示克制图标或短提示。
  - _需求：4_

- [x] 1.3 提供换乘和厕所分组视图数据
  - 输出当前物理站的全部可换乘线路。

## 阶段 2：首页布局与交互（本轮实现）

- [x] 2.1 重构顶部计算起点控制

  - _需求：2_

- [x] 2.2 恢复苹果风并固定五站密度
  - 将主体密度调整为一屏固定 5 站，通过缩小间距和内边距实现，不缩小原有字体。
  - 恢复大圆角、柔和阴影、白灰层级和克制动效。
  - 固定左侧连续轨道，区分智能定位针与可点击站点圆点；只让右侧中心卡片承担浏览高亮。
  - _需求：1、7_

- [x] 2.3 增加显式换乘入口
  - 在换乘站右侧增加半透明提示。
  - 展示全部可点击线路胶囊，并让横滑与点击复用同一切线逻辑。
  - _需求：5、7_

- [x] 2.4 压缩顶部控制与同步状态
  - 城市改为无下拉图标的胶囊入口，并提供第一版城市选择底部面板。
  - 顶部合并为两行；点击起点站名选择站点，自选模式显示“自选起点｜恢复定位”。
  - 同步状态使用绿色／蓝色圆点、紧凑时间和常驻轻量更新入口；刷新图标仅在请求期间旋转。
